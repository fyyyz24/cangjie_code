# Cangjie Code Repository

This is an open-source repository for Cangjie programming language developers to store and share Cangjie code.

## About Cangjie

Cangjie (仓颉) is a modern programming language developed by Huawei. It is designed to be safe, efficient, and easy to learn.

## Repository Structure

```
cangjie_code/
├── src/           # Source code files
├── examples/      # Example programs
├── LICENSE        # Apache 2.0 License
└── README.md      # This file
```

## Getting Started

### Prerequisites

- Cangjie compiler (cjc) installed
- Cangjie SDK

### Building

To build a Cangjie project:

```bash
cjc build
```

### Running

To run a Cangjie program:

```bash
cjc run
```
